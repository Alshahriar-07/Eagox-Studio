# Eagox Studio

Professional software engineering studio website for **Eagox Studio**, founded by **Al Shahriar Sayon** (also known online as **Al Shahriar Sowan**).

## What Eagox Studio does

Eagox Studio designs and builds professional websites, responsive business websites, portfolios, full-stack web applications, SaaS products, Android/mobile apps, desktop software, AI-powered tools, API integrations, and custom software systems.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- Three.js / Motion where used by the UI
- Formspree for contact and order submissions
- Public GitHub API for project repository statistics

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production site is a static Vite build in `dist/` and does not require Google AI Studio, Gemini credentials, Express, or a paid AI subscription to run.

## SEO and AI discovery

The project includes semantic homepage copy, title/description/social metadata, Organization/Person/Website JSON-LD, `robots.txt`, and `llms.txt`. The site should be deployed on the final production domain and then submitted to Google Search Console.

`llms.txt` is provided for AI systems that choose to consume it. Google Search documentation currently says `llms.txt` is not required for Google Search and is not a direct ranking factor; normal crawlability, helpful content, technical SEO, and structured data remain important.
