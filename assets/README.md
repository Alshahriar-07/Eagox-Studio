# Eagox Studio — Brand Assets

Generated from the supplied Eagox logo artwork.

## Branding
- `eagox-icon.*` — icon/mark
- `eagox-wordmark.*` — EAGOX wordmark
- `eagox-logo-horizontal.*` — icon + EAGOX horizontal lockup
- `*-white.*` — white versions for dark/glass UI
- `eagox-logo-dark-preview.png` — preview on dark background

## Favicon
Multiple PNG sizes, `favicon.ico`, `apple-touch-icon.png`, and 192/512px web-app icons.

## Social
- `eagox-banner.jpg` — supplied banner optimized for web
- `eagox-og-image.jpg` — 1200×630 Open Graph image

## Notes
The transparent logo PNGs are the primary visual assets. SVG files are self-contained SVG wrappers containing the transparent PNG artwork, so they can be used directly as SVG assets without external file dependencies.

For the website, prefer:
- Dark/glass UI: `eagox-logo-horizontal-white.svg`
- Light UI: `eagox-logo-horizontal.svg`
- Favicon: `favicon.ico` or `eagox-favicon-32.png`
- Apple/mobile icon: `apple-touch-icon.png`
